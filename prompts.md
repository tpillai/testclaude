1. **Create the base API**

2. **Add tests**
   > write a test case for this application

3. **Add PostgreSQL, React frontend, and Docker**
   > i want to use a postgress db to store the todo. create a frontend using react. i want to use docker to deploy it.

4. **Push to Docker Hub**
   > i want to push this to docker hub https://hub.docker.com/repositories/tpillai

5. **Git + README**
   > i want to push this to git repo. write a readme along with steps to use it. also give manual commands like to create image and push it to docker hub.

6. **Document prompts**
